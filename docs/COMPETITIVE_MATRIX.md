# 竞品与生态对照

> 目标不是“比谁功能多”，而是说明 GhostValley 的生态位置：AI 训练/记忆实验台，而不是通用 LLM 客户端。

| 项目/方案 | 定位 | 强项 | 与本项目关系 |
|---|---|---|---|
| Python 幽灵谷原型 | 概念原型 | 五大模块概念 | 本项目上游；仅概念，未公开、无第三方许可 |
| `mizchi/llm` | LLM 客户端 | Provider/Mock、消息类型、token 预算 | 本项目不重复造客户端；未来可接为 Provider |
| `moonbitstack/moonmuse` | LLM 网关/方言 | Provider+Dialect、structured、layers | 本项目聚焦训练/记忆，不竞争网关 |
| `colmugx/posoco` | Agent 框架 | 六边形端口、可审计组合 | 本项目可用其端口思想扩展 MCP/Provider |
| `pinyin-toolkit` | 拼音工具 | Unihan、搜索键、可审计匹配 | 不同领域，仅作为“工程质量标杆”参考 |
| GhostValley（本项目） | AI 压力训练/记忆实验台 | 困境→感悟→记忆/遗忘→评估→回放；Qwen 回放+质量层；四后端门禁 | 生态增量：可复现的训练/记忆实验台 |

## 可量化对照（本项目内部基线）

| 指标 | 结果 |
|---|---|
| 测试 | 503 × 4 后端 |
| 覆盖率 | 91.6%（1356/1480） |
| 变异 | 13/13 KILLED |
| Qwen 基础语料 | 9/12 达质量门槛 |
| Qwen 精选语料 | 23/24 达质量门槛 |
| 144 次评测 | 782ms / 36.7 字 / 22.9 tokens；稳定性 0.238 |
| 可运行示例 | 5 个（含 Qwen 精选） |

## 尚未形成对照的项（诚实披露）

- 无下游项目采用数据（0 dependents），生态增量仍以“可复用能力 + 示例 + 在线演示”呈现。
- 无实时模型/embedding/MCP/CLI/benchmark；见 `docs/known-gaps.md`。
- 0.5B 输出不可作为事实/安全结论；仅用于回放与评测。

## 决赛叙事建议

- 不与 LLM 客户端比“连接多少模型”，而与“训练/记忆实验台”比“可复现与安全边界”。
- 用 144 次评测 + 质量层证明“知道模型不可靠”，而不是宣称模型很强。
- 用 503×4 / 91.6% / 13-13 / 36 项文档门禁证明工程可信度。
